02. Interface de Linha de Comando (CLI)

A CLI exige que o usuário digite comandos de texto específicos em um terminal para que o sistema operacional os execute.

É uma interface extremamente rápida, leve e precisa, sendo muito utilizada por desenvolvedores e administradores de sistemas.
