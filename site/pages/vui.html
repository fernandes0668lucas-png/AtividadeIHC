05. Interface de Voz do Usuário (VUI)

A VUI permite que os comandos sejam dados falando diretamente com o dispositivo, utilizando inteligência artificial para o processamento.

Assistentes virtuais, como Alexa e Siri, são os maiores exemplos, promovendo alta acessibilidade para pessoas com limitações motoras.
